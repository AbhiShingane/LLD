The Elevator system LLD is for supporting the multiple elevator in the building.
F requirements.
1. request to go to floor.
2. supporting mulitple elevators


Non functional requirments:
1. scalabale
2. low latency
3. modular


There is support of n number of elevator which is controlled through the controller..

These are below topics on which this design would be based on:
- Elevator objects
- Floor requests
- Direction logic
- Scheduling algorithm
- Controller design
- Communication between controller and elevators
