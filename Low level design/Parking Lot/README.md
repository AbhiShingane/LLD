Parking lot Low level Design

Functional Requirements:

1. parking lot has multiple floors
2. each floor has multiple spots.
3. Different types of spots according to vehicle 
    - 2 wheelar spot
    - four wheelar spots
    - loading vehicle spots

4.  Different types of vehicle supported
    - motar cycle
    - car
    - truck

5. vehicle can park in compatiable parking spot


Lets figure out the Entry and Exit flow:

Entry flow:
- Vehicle arrives
- system allocates the parking spot
- generates the ticket

Exit flow:
- scan the ticket.
- calculate the fair and do the payment
- release the parking spots
- vehicle exists
